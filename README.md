# FrameCut

> เว็บตรวจงานวิดีโอ (video review) สำหรับทีมคอนเทนต์ — repo: `Video-Feedback-Content`

เว็บตรวจงานวิดีโอสำหรับทีมคอนเทนต์ — คอมเมนต์ผูกกับ timestamp พร้อมจับภาพเฟรมและวาดมาร์กอัป,
วางแผนสต็อกตามประโยคที่พูด, ส่งออกเป็น Google Sheets

**ใช้งาน:** เปิดลิงก์ที่ deploy ไว้ หรือดาวน์โหลด `index.html` ไปเปิดในเบราว์เซอร์ก็ได้ — ทั้งไฟล์ทำงานฝั่งเบราว์เซอร์ทั้งหมด ไม่มีเซิร์ฟเวอร์ ไม่มีฐานข้อมูล ข้อมูลทุกอย่างเก็บในเครื่องผู้ใช้เอง

## ความสามารถ

### รับวิดีโอได้ 3 ทาง
| แหล่ง | จับเฟรม | อ่านเวลาอัตโนมัติ |
|---|---|---|
| อัปโหลดไฟล์ / ลาก-วาง / ลิงก์ `.mp4` ตรง | ✅ เต็มความละเอียด | ✅ |
| YouTube (ลิงก์ปกติ / Shorts / youtu.be) | ✅ ผ่านปุ่ม 🎥 จับภาพจากแท็บ | ✅ (YouTube IFrame API) |
| Google Drive (แชร์ "ทุกคนที่มีลิงก์") | ✅ ผ่านปุ่ม 🎥 หรือ "ลองสตรีมตรง" | พิมพ์เวลาเอง / สตรีมตรง |

### คอมเมนต์
- ผูกกับ timecode แบบ `m:ss:ff` คลิกเพื่อกระโดดไปจุดนั้น
- จับเฟรมจริงเป็นรูปฝังในคอมเมนต์ (กด `C` หรือ 💬) พร้อมมาร์กอัป: กรอบ / วงกลม / ลูกศร / ปากกา / สติกเกอร์
- หมุดบน timeline เป็นอักษรย่อชื่อคนคอมเมนต์ (สีต่อคน)
- แท็บ ยังไม่ได้รับการแก้ไข / แก้ไขแล้ว / ทั้งหมด + ค้นหา
- ตาราง Comment Log แก้ข้อความ/ชื่อ/หมวด/สถานะได้ในตาราง

### แผนวางสต็อกตาม timestamp
- วางสคริปต์ → "แยกประโยค" → เล่นวิดีโอแล้วกด `S` ทุกครั้งที่ประโยคใหม่เริ่มพูด
  ระบบลง IN ของประโยคนั้นและปิด OUT ของประโยคก่อนหน้าให้ พร้อมแนบเฟรมอ้างอิง
- แถบ timeline แสดงช่วงสต็อก คลิกกระโดดได้ · ปุ่ม IN/OUT ตั้งเวลาจากตำแหน่งเล่นปัจจุบัน
- ช่องกรอกชื่อ/ลิงก์สต็อกที่จะวาง + หมายเหตุ

### Export
| ปุ่ม | ได้อะไร |
|---|---|
| 📋 คัดลอก + เปิด Google Sheets | คัดลอกตารางเป็น TSV แล้วเปิดชีตใหม่ให้ วาง `Cmd/Ctrl+V` ได้เลย ไม่ต้องตั้งค่าอะไร |
| 🚀 ส่งเข้า Google Sheet ตรง | ผ่าน Apps Script Web App ได้ 2 ชีต (คอมเมนต์ + แผนสต็อก) พร้อมภาพเฟรมฝังในเซลล์ |
| ⬇ CSV | UTF-8 BOM เปิดใน Excel ภาษาไทยไม่เพี้ยน |
| ⬇ ZIP | `comments.csv` + `stock-plan.csv` + ภาพเฟรมทุกอันตั้งชื่อตาม timecode |

### กันงานหาย
- Autosave ลงเบราว์เซอร์ทุกครั้งที่แก้ไข (เปิดใหม่จะถามว่ากู้คืนไหม)
- Undo / Redo 60 ขั้น ครอบคลุมทั้งคอมเมนต์และแผนสต็อก (`Ctrl+Z` / `Ctrl+Shift+Z`)
- ดาวน์โหลด/โหลดไฟล์ backup `.json` (รวมภาพเฟรม) เพื่อย้ายเครื่องหรือส่งต่อ

## คีย์ลัด

| ปุ่ม | ทำอะไร |
|---|---|
| `Space` | เล่น / หยุด |
| `←` `→` | เดินทีละเฟรม (กด `Shift` = 1 วินาที) |
| `C` | จับเฟรมเข้าช่องคอมเมนต์ |
| `S` | จับเวลา IN ให้ประโยคถัดไปในแผนสต็อก |
| `Ctrl/Cmd + Enter` | โพสต์คอมเมนต์ |
| `Ctrl/Cmd + Z` / `+ Shift + Z` | Undo / Redo |
| `Ctrl/Cmd + S` | ดาวน์โหลดไฟล์ backup |

## จับเฟรมจาก YouTube ทำได้อย่างไร

เบราว์เซอร์ห้ามอ่านพิกเซลจาก iframe ข้ามโดเมน (same-origin policy) จึงดึงภาพจากตัวเล่น YouTube ตรงๆ ไม่ได้
เครื่องมือนี้เลี่ยงด้วย **Screen Capture API** ของเบราว์เซอร์เอง:

1. กดปุ่ม 🎥 → เลือก **"แท็บนี้ (This tab)"**
2. ระบบ crop เฉพาะกรอบวิดีโอออกจากภาพแท็บให้อัตโนมัติ แล้วประกอบมาร์กอัปที่วาดไว้ทับ
3. ได้ภาพเฟรม + timestamp เข้าคอมเมนต์เหมือนโหมดไฟล์

ข้อจำกัด: ความคมได้เท่าที่แสดงบนจอ (ขยายวิดีโอให้ใหญ่ก่อนจับ) · ต้องใช้ Chrome/Edge เดสก์ท็อป ·
ขณะเลือกเครื่องมือวาด ปุ่มควบคุมของ YouTube จะกดไม่ได้ ให้ใช้ปุ่มเล่น/เดินเฟรมของเว็บนี้หรือกด ✋ ก่อน

> สำหรับงานตรวจจริง แนะนำใช้ไฟล์ master (MP4 ก่อนอัปโหลด) จะได้เฟรมคมชัดเต็มความละเอียดและตรงเฟรมที่สุด

## ตั้งค่า "ส่งเข้า Google Sheet ตรง" (ทำครั้งเดียว)

1. เปิด [script.google.com](https://script.google.com/home/projects/create) → New project
2. ลบโค้ดเดิม วาง [`apps-script-export.gs`](apps-script-export.gs) ทั้งไฟล์ → บันทึก
3. Deploy → New deployment → type **Web app**
4. Execute as **Me** / Who has access **Anyone** → Deploy → อนุญาตสิทธิ์
5. คัดลอก Web app URL (ลงท้าย `/exec`) ไปใส่ในหน้า ⚙ ตั้งค่า ของ FrameCut

## ความเป็นส่วนตัว

ไม่มี backend ไม่มี analytics ไม่มีการอัปโหลดวิดีโอหรือคอมเมนต์ไปที่ใด — ทุกอย่างอยู่ในเบราว์เซอร์ของผู้ใช้
ยกเว้นกรณีกด "ส่งเข้า Google Sheet ตรง" ซึ่งจะส่งข้อมูลไปที่ Apps Script Web App ในบัญชี Google ของผู้ใช้เอง

## เทคนิค

ไฟล์เดียว ไม่มี dependency ไม่มี build step — HTML + CSS + vanilla JS
รวมตัวเขียน ZIP (deflate store + CRC32) เขียนเองในไฟล์ จึงทำงานแบบออฟไลน์ได้ทั้งหมด
