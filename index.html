วิธีใช้ & ข้อจำกัดที่ควรรู้

  

    2 โหมดการทำงาน
    
    
      
  • โหมด A — ไฟล์ตรง (อัปโหลด / ลิงก์ .mp4 ตรง / Drive ที่แชร์ “ทุกคนที่มีลิงก์”):
        จับเฟรมจริงเป็นรูปได้ วาดกรอบ–วงกลม–ลูกศร–สติกเกอร์ทับได้ ภาพจะฝังในคอมเมนต์
    • 
      
  • โหมด B — YouTube / Drive preview: เบราว์เซอร์ห้ามดึงภาพจาก iframe ข้ามโดเมนโดยตรง
        → เก็บ timestamp + ลิงก์กระโดดไปวินาทีนั้น
    • 
    

    จับเฟรม YouTube ให้ได้ — 3 ทาง (เรียงจากดีที่สุด)
    
    
      
  • 1. ใช้ไฟล์ master (MP4 ก่อนอัปโหลด หรือดาวน์โหลดจาก YouTube Studio ของตัวเอง) → โหมด A
        ได้เฟรมคมชัดเต็มความละเอียด ตรงเฟรม และเดินทีละเฟรมได้ — แนะนำสำหรับงานตรวจจริง
    • 
      
  • 2. กดปุ่ม 🎥 “จับภาพจากแท็บ” — ใช้ Screen Capture API ของเบราว์เซอร์เอง:
        อนุญาตครั้งเดียวต่อการเปิดหน้า เลือก “แท็บนี้ (This tab)” แล้วจับเฟรม + วาดมาร์กอัปบน YouTube/Drive ได้เหมือนโหมด A
        
    ข้อจำกัด: ภาพได้เท่าความละเอียดที่แสดงบนจอ (ขยายวิดีโอให้ใหญ่ก่อนจับจะคมกว่า) ·
        ต้องใช้ Chrome/Edge เดสก์ท็อป (Safari เลือกเฉพาะแท็บไม่ได้ จะได้ทั้งจอ) · ถ้าปิดหน้าเว็บต้องกดอนุญาตใหม่
    • 
      
  • 3. แคปหน้าจอเองแล้ววาง — Cmd+Shift+4 / Win+Shift+S
        แล้วกด Cmd/Ctrl+V ในช่องคอมเมนต์ ระบบแนบภาพให้พร้อม timestamp
    • 
    

    

      หมายเหตุ: การดึงเฟรมจาก YouTube ตรงๆ ด้วยโค้ด (storyboard/proxy) ทำได้ทางเทคนิคแต่ต้องมีเซิร์ฟเวอร์กลาง
      ภาพหยาบ ไม่ตรงเฟรม และขัดเงื่อนไขการใช้งานของ YouTube — จึงไม่ทำในเครื่องมือนี้
    

    แผนวางสต็อกตาม timestamp
    
    
      
  • วางสคริปต์ → แยกประโยค → เล่นวิดีโอแล้วกด S ทุกครั้งที่ประโยคใหม่เริ่มพูด
        ได้ IN ของประโยคนั้น + OUT ของประโยคก่อนหน้าอัตโนมัติ (โหมด A แนบเฟรมอ้างอิงให้ด้วย)
    • 
      
  • ปุ่ม IN / OUT ในแต่ละแถว = ตั้งเวลาจากตำแหน่งเล่นปัจจุบัน · แถบ timeline สีม่วงคลิกกระโดดได้
    • 
    

    คีย์ลัด
    
    
      
  • Space เล่น/หยุด · ←→ เดิน 1 เฟรม · Shift+ลูกศร = 1 วินาที
    • 
      
  • C จับเฟรม · S จับเวลาประโยคถัดไป · Ctrl+Enter โพสต์คอมเมนต์
    • 
      
  • Ctrl+Z Undo · Ctrl+Shift+Z Redo · Ctrl+S ดาวน์โหลด backup
    •
